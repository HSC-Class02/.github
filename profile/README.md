# HSC-Class02

> **2026년 2학기 「기업이 원하는 AI」 2분반 프로젝트 공간입니다.**

## 프로젝트 목표

1. AI 윤리에 중요한 가치를 두며, 프로젝트 참여 학생 모두 UNESCO의 AI 윤리 과정을 수료했습니다.  
   [![AI 윤리에 관한 글로벌 MOOC](https://img.shields.io/badge/AI%20윤리에%20관한%20글로벌%20MOOC-Coursera-0056D2?logo=coursera&logoColor=white)](https://www.coursera.org/learn/global-mooc-on-the-ethics-of-ai)
2. DART 공시 데이터를 활용해 상장 기업 재무 분석 AI Agent를 만들고 분석 보고서를 작성합니다.
3. 공공 데이터를 활용해 Analytics AI Agent를 만들고 분석 보고서를 작성합니다.

## 소개

HSC-Class02는 기업과 산업에 관한 데이터를 분석하고 프로젝트 결과를 정리하는 학습 공간입니다. 공개 데이터를 수집·정리하고, 재무 분석이나 대시보드와 같은 결과물로 구현합니다.

각 저장소에는 프로젝트 목적, 사용 방법, 데이터 출처와 분석 범위를 기록해 학습과 협업에 활용합니다.

1. We place a high value on AI ethics, and all students participating in these projects have completed UNESCO’s AI ethics course.

## About

HSC-Class02 is a learning space for analyzing company and industry data and documenting project outcomes. We collect and organize public data and turn it into financial analyses, dashboards, and other project outputs.

Each repository documents the project’s purpose, usage instructions, data sources, and scope of analysis to support learning and collaboration.

## How to Use the Projects

1. Select a repository of interest and read its `README` for the project’s purpose and instructions for running it.
2. Review the data sources, collection period, scope of analysis, and limitations.
3. Store required API keys in the repository’s GitHub Actions Secrets. Do not expose them directly in code or documentation.
4. Use the repository’s `Issues` or Pull Requests for questions and suggestions. First check whether these features are enabled in the repository.

## Shared Principles

- Record the sources of data and analytical results.
- Do not fill in unverified values arbitrarily. Clearly state limitations and missing information.
- Do not upload sensitive information, such as API keys, passwords, or personal information, to public repositories.
- Project results are intended for learning and informational purposes. Check the original sources and latest disclosures before making investment decisions.
